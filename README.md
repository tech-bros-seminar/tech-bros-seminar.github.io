# Tech bros seminar — GitHub Pages

A static academic seminar site for mathematical arguments generated by AI.
The seminar reads these arguments, tries to understand them, and prepares
clearer versions after checking the proofs. The build reads the selected
public catalogue and never reads the private research archive.

## Website and repository

- Website: https://tech-bros-seminar.github.io/
- Public repository: https://github.com/tech-bros-seminar/tech-bros-seminar.github.io
- Deployment status: https://github.com/tech-bros-seminar/tech-bros-seminar.github.io/actions

The website is built and published by GitHub Pages after successful checks on
`main`. The private research notebook remains separate.

This migration uses the original website source at commit
`3b7ff93e9281d79972062746e3792a99ea996985`, preserving its design, content,
manuscripts, full review notes, and locally hosted fonts. It supersedes the
previous reconstructed migration ZIP. No private research archive, hosting
credentials, Site account configuration, or design conversation notes are included.

## Local development

Python 3 is the only build dependency. The presentation uses locally hosted Noto fonts.

Keep the cream-and-green visual design, typography, and page layout. The hero
uses a small, textured pen-and-ink portrait of Évariste Galois, with recognizable
historical facial features and futuristic synthetic panels and light seams.
Its maximum displayed height is 320px on desktop and 260px on mobile. No gears,
antique mechanisms, or visible image caption. A cybernetic brain serves as the
header and tab mark.
Use the name **Tech bros seminar**, with a capital T. Content updates should
preserve this style and the separate AI generated / Human reviewed categories.

```sh
python -B scripts/build.py
python -B scripts/check_site.py
python -B -m unittest discover -s tests -v
```

The build recreates `dist/` from `content/catalog.json`, `assets/`, and the
publication files explicitly referenced by the catalogue. Serve `dist/` with a local static server, for example
`python3 -m http.server 8000 --directory dist`. Do not commit temporary QA pages.

## Publishing and future edits

The repository includes `.github/workflows/pages.yml`. Select **Settings →
Pages → Source → GitHub Actions**. A push to `main` builds and checks the site,
then deploys only `dist/`; pull requests run the checks without deploying.
The generated `dist/` directory is ignored by Git and recreated by the workflow.
No personal access token or third-party hosting account is required.

Edit `content/catalog.json` and the explicitly selected files in `content/files/`
for publication updates. Preserve the publication metadata and review record.
The private research notebook remains separate: routine research reports are
not copied or published automatically.

The builder sets canonical and sitemap URLs with `ORIGIN` in `scripts/build.py`.
If the intended organization name changes, update that value and this README
before publishing. This is configured for an organization site at the domain
root, not a project site under a repository path.

The seminar shares its papers on its own website and does not pursue journal
submission. Keep the public process focused on sharing the arguments, AI checks,
Lean status, and the seminar's understanding and review.

The two public types are **AI generated** (`preprints`) and **Human reviewed**
(`solutions`). Ask AI to polish and review a solution manuscript and formalize
it in Lean when possible, then publish the AI generated version before human
review. Record its actual scope, AI checks, attribution, and Lean status.

For every AI generated paper, include its public prompts and conversations in
the ordered `prompt_links` array on the preprint record. Each item has exactly
`label` and `url`, where `url` is a public absolute HTTPS link. Several links
can document different research or review conversations. Use links actually
provided for publication; never invent a transcript or copy private material.
Older records without links remain valid and display a clear not-yet-published
message. The paper page lists the links under **Prompts and conversation**;
the manuscript's download links include **Prompts** when links are available.

Problem-list badges are the row's navigation: **In progress** links to the
problem; **AI generated solution** and **Human reviewed solution** link to the
latest active full-solution manuscript in the corresponding category. Newer
partial or withdrawn papers do not replace that destination. Publication date
sorts first, then natural numeric version order, then slug as a stable tie-break.

After the seminar understands and checks the proof, publish a new, clearer
Human reviewed version with the actual reviewers and a link to the AI original.
Keep the original available. AI review and Lean checking are separate from
human review. Partial or unavailable formalization does not block AI publication.
Store approved versioned artifacts below `content/files/` and reference each
one explicitly in the catalogue. Keep prior versions and record corrections
or withdrawals openly.

The checks validate files and metadata. They cannot authenticate a reviewer,
establish novelty, or certify mathematical correctness. Never fill required
fields with invented review or acceptance.

## Sources and assets

Problem statements are paraphrased from the editors' Kourovka Notebook; exact
edition, page, attribution and source links are recorded in the catalogue.
The cybernetic Galois illustration and locally hosted fonts are included in `assets/`.
The font license is included in `assets/fonts/LICENSE.txt`.

`assets/cybernetic-galois-v3.png` was generated with the built-in image-generation
tool on 6 November 2026, editing the exact image selected by the user. The current
portrait restores Galois's historical likeness and hand-drawn ink texture, while
retaining a futuristic synthetic cheek and neck. It has no visible caption;
its accessible alternative text identifies it as AI-generated.
The supporting likeness reference was the public-domain
[Alfred Galois portrait on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Galois-1848.jpg).

`assets/cybernetic-brain.svg` and `assets/favicon.svg` are original vector marks:
a green brain silhouette containing pale circuit traces and round terminals.
Their visual reference is the brain symbol on the user's
[Wikipedia reference page](https://fr.wikipedia.org/wiki/Contr%C3%B4le_des_capacit%C3%A9s_de_l%27IA).
No image pixels or paths were copied.
